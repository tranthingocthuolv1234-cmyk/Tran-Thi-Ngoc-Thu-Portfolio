# Tran Thi Ngoc Thu — Business Analyst Portfolio

A static professional portfolio featuring a responsive homepage and detailed Business Analysis case studies for VirtuHire and ParkFlow B.

## Technology

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript

No packages, framework, build tool, backend, or database are used.

## Local preview

From this folder, run:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000/>.
